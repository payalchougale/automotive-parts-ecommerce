# Automotive Parts E-commerce Website
UCT Full Stack Internship Project

---

# 1. About UCT

UCT is a technology company that provides training and internship programs for students in software development. The company focuses on real-world industry projects to help students gain practical experience in full stack development.

---

# 2. Project Background

Automotive parts are essential for vehicle maintenance and repair. Traditionally, customers must visit physical stores to find parts, which can be time-consuming. An online platform allows customers to easily browse, search, and purchase automotive parts from anywhere.

---

# 3. Problem Statement

The objective of this project is to build a full stack web application that allows users to browse automotive parts, search products, and place orders online while enabling administrators to manage products and orders efficiently.

---

# 4. System Architecture

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- PHP

Database:
- MySQL

Server:
- XAMPP

The system follows a client-server architecture where the frontend communicates with the backend APIs, and the backend interacts with the database.

---

# 5. Implementation

The project includes the following modules:

User Module
- Browse automotive parts
- Search products
- Filter by category
- Add products to cart

Admin Module
- Add new products
- Update product details
- Delete products
- View orders

Database Module
- Store users
- Store products
- Store cart items
- Store orders

---

# 6. Results

The developed system successfully allows users to:

- View automotive parts
- Search and filter products
- Add products to cart
- Place orders

Administrators can manage products and view orders through the admin dashboard.
